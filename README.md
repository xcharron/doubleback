# Doubleback

**A camera app that records the front and back cameras at once, both in 4K, with up to two minutes of pre-roll.**

[doublebackcam.com](https://doublebackcam.com)

Doubleback is in beta. This repository is a public showcase; the source is private.

## What it does

- **Both cameras, one take.** The front and back cameras record together, each as a clean full-size file, plus a combined video ready to post.
- **Pre-roll.** The app keeps the last two minutes before you press record, so the moment you reacted to is in the file.
- **4K on both.** Most apps offer two cameras or pre-roll. Doubleback does both, in 4K.

## How it was built

Built from PREYR's camera core and spun out as its own product: proof that the core can be rebranded and reused. Free with a watermark; a one-time unlock removes it, and a second upgrade puts your own logo on the footage.

Stack: React Native, Python (FastAPI), Railway, RevenueCat.
